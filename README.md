# VHDiff

Heart sound audio showcase for individual valvular diseases and their combinations.

- [Generated Heart Sounds](https://zhj12399.github.io/VHDiff/): 32 configurations, two audio examples each.
- [Real Database Audio](https://zhj12399.github.io/VHDiff/real.html): 40 examples from 20 observed configurations.

Each audio example includes waveform, Log-Mel and MFCC views.

We thank Beijing Anzhen Hospital for its support.
