About the audio and signal views

AS: aortic stenosis · AR: aortic regurgitation · MS: mitral stenosis · MR: mitral regurgitation · TR: tricuspid regurgitation. Binary codes follow this order, with 1 indicating presence and 0 indicating absence. Normal is 00000.

Generated labels specify the requested condition. Database support refers to exact configurations in the original clinical cohort. This research gallery presents illustrative samples selected for clearly identifiable heartbeat pulses, envelope periodicity and signal integrity. Click a signal image to inspect the high resolution view.

Playback WAV copies are interpolated to 8 kHz for browser compatibility. Signal visualizations use the original 2 kHz clips.

Waveform

The stored 2 kHz waveform over 3 seconds, displayed with a clip specific amplitude range and the original amplitude units. The WAV player and the plots represent the same clip.

Log-Mel

64 Mel bands, FFT 1,024, Hann window 64 samples and hop 32 samples. Power is shown relative to each clip’s maximum, over −80 to 0 dB.

MFCC

Coefficients C1–C20, computed from the displayed Log-Mel representation using an orthonormal discrete cosine transform. The energy coefficient C0 is excluded, and a common color scale is used across all examples.
