About the database excerpts

AS: aortic stenosis · AR: aortic regurgitation · MS: mitral stenosis · MR: mitral regurgitation · TR: tricuspid regurgitation. Binary codes follow this order. Normal is 00000.

These illustrative clips come from the training partition. Two different recordings are used when available. Configurations represented by a single recording show two different excerpts from that recording. The original cohort includes 12 further possible configurations with zero recording support, which can be explored in the generated gallery.

Playback WAV copies are interpolated to 8 kHz for browser compatibility. Signal visualizations use the original 2 kHz clips.

Waveform

Three second excerpts of the prepared clinical recordings at 2 kHz. The vertical range follows each clip’s amplitude so that heartbeat pulses remain visible.

Log-Mel

64 Mel bands, FFT 1,024, Hann window 64 samples and hop 32 samples. Every plot uses the same −80 to 0 dB color range relative to the clip maximum.

MFCC

Coefficients C1–C20 from the displayed Log-Mel representation. C0 is excluded. The extraction settings and color scale are shared with the generated clips.
